# 🎟️ Event Management Website

An **Event Management System** built using **Django** and **SQLite** that allows users to explore, create, and manage events seamlessly. The platform is designed with a responsive UI and dynamic templates for event listing, registration, and management.

---

## 🚀 Features

- 🏠 **Home Page:** Displays featured and upcoming events.  
- 🧾 **Event Listing:** View all available events with details like date, location, and organizer.  
- 👤 **User Registration & Login:** Secure authentication system using Django’s built-in auth module.  
- 🗓️ **Event Creation:** Registered users can create and manage their own events.  
- 📝 **Event Registration:** Attendees can register for events online.  
- 💬 **Testimonials Section:** Users can share feedback about events.  
- ✉️ **Newsletter Subscription:** Visitors can subscribe for event updates.  
- 📱 **Responsive Design:** Fully optimized for mobile, tablet, and desktop devices.

---
